# Russia Regime Early-Warning Monitor

This project records seven weekly analyst-coded indicators on a 1–5 scale and two weighted composite indices.

Canonical palette: `#0d1f3c` / `#1a3761` / `#dbad50` / `#82a0bc` / `#e8edf3`.

Every weekly observation should include a concise analytical narrative and article-level citations with source name, publication date, title, and URL. Past observations with publisher names only remain marked as legacy provenance until verified.
